# BSN Studio
Node.js 20+ recommandé. `npm install`, puis `npm run dev`. Ouvrir http://localhost:3000. Pour Vercel, importer le dépôt Git, choisir Next.js et déployer. `npm run build` vérifie la compilation.

Personnalisation : ajouter hero.jpg, automotive.jpg et motion.jpg dans public/ (photos personnelles). Sans ces fichiers, les fonds neutres restent visibles. Modifier les projets et remplacer contact@example.com dans app/page.tsx par votre adresse réelle avant publication. Les catégories sont des exemples éditoriaux, pas des réalisations attestées. Les styles sont dans app/globals.css. Pas de backend ni de formulaire serveur. Les interactions utilisent React. Aucune dépendance Tailwind ou Framer Motion nécessaire.
